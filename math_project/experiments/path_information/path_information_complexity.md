# Path information, state refinement, and computational cost

## Finding

The pentagon theorem proves that no nonzero additive image of the signed rotation count is determined by the original endpoints. It does not force expensive computation: adding a signed counter repairs the state description cheaply, and the bidirectional tree-rotation system admits efficient constructive reachability.

There are computational tasks where forgetting distinctions provably costs correctness. Equality gives an exact lower bound on summary size; unstructured witness search gives an exponential query lower bound in witness length. Both require explicit computational-model restrictions. Neither supplies a P-versus-NP separation.

This note separates existing Lean results, mathematical deductions made here, and sourced complexity results. The deductions and lower-bound proofs below have not been formalized in Lean. No Lean source is changed by this investigation.

## What the existing Lean theorem establishes

[DirectedReassociation.lean](../../MathProject/DirectedReassociation.lean) defines a reversible rotation step with sign +1 for right rotation and -1 for left rotation, and sums signs along paths. It separately defines unsigned length. `pentagon_sign_additive_quotient_trivial` proves, for every abelian group G and additive homomorphism f : Z -> G, that equating the two pentagon route images forces f = 0.

The proof uses their signs 2 and 3: equality kills f(1), and 1 generates Z. This is about additive images of the signed count, not every measurement of paths or the full `(length, sign)` valuation. `rotation_sign_no_vertex_potential` separately rules out representing the original edge sign as an integer state-potential difference.

Given only endpoints, asking for the sign of the actual traversed route is not a well-defined computational function: identical input would require different answers. Additional computation time cannot reconstruct information absent from the input. Enlarging the state repairs the specification. A runtime lower bound instead concerns a well-defined answer whose necessary information is available but costly to obtain.

An immediate generalization is to let D be the subgroup of Z generated by all differences sigma(p) - sigma(q) for parallel paths p and q. An additive f makes sigma endpoint-independent exactly when D is contained in ker(f). Thus Z/D is the universal additive endpoint-independent image of sigma. The pentagon puts 1 in D, so D = Z and the universal image is trivial. This is a deduction, not an additional checked Lean theorem.

## Cheap repair by changing the states

Replace a tree s by a pair (s,k), where k is an integer. Lift an edge e : s -> t to

```text
(s,k) -> (t,k + sign(e)).
```

Then H(s,k) = k is an exact potential: its edge difference equals sign(e). Starting at (s,0), the pentagon routes end at (t,2) and (t,3). They no longer have the same lifted endpoint, so the collapse theorem does not apply to their identification there.

For a path of at most T steps, |k| <= T, so the additional counter needs O(log(T+1)) bits. In particular, exponentially many elapsed steps need only linearly many counter bits when T = 2^n. Executing the steps and representing their aggregate are different costs. Enlarging the target group cannot rescue additive descent, whereas enlarging the source state can.

The pentagon also supplies a matching lower bound for this exact representation task. Its closed path has length 5 and sign -1; reversing it gives length 5 and sign +1. Set m = floor(T/5). At the same four-leaf base tree, repeating either loop produces every signed value k in [-m,m] within T steps. Any deterministic state refinement that lifts every such path from a fixed initial state and represents the original integer sign as a potential difference must give these 2m+1 histories different final refined states: their potential values differ by k. A b-bit refined state over that fixed base tree therefore needs

```text
b >= ceil(log2(2 floor(T/5) + 1)).
```

Together with the counter construction, this proves a tight asymptotic Theta(log(T+1)) bound on the number of bits needed over a fixed base state, for histories of at most T steps. This is an original mathematical deduction from the checked loop values, not a Lean-formalized theorem or a lower bound for deciding reachability. It precisely quantifies the repair forced by this particular obstruction.

## The rotation system is a counterexample to an unrestricted hardness bridge

For a full binary tree with n leaves, normalize to a right comb using right rotations at nodes on the current right spine whose left child is internal. At such a node the rotation

```text
((a b) c) -> (a (b c))
```

adds exactly one internal node to the global right spine. A full binary tree has n-1 internal nodes. For n >= 2 the initial spine has at least one, so at most n-2 such rotations are required. When no spine node has an internal left child, the tree is the right comb. The contextual rotation constructors in the file allow these operations below the root.

Two n-leaf trees can therefore be connected through the comb in at most 2(n-2) bidirectional rotations, reversing the second normalization. With an explicit tree representation, discovering and executing these rotations takes polynomial time even with a simple implementation that rescans or copies the tree. For n = 1 the tree is unique.

This constructive argument is not yet Lean-formalized. It shows why a bridge asserting that every efficient path constructor induces the forbidden potential would be false: this algorithm chooses one route without preserving the signed costs of all routes.

An independent finite implementation check enumerated all 2,056 trees with one through nine leaves and confirmed a unique comb endpoint and the exact rotation count n-1 minus the initial number of internal nodes on the right spine. This finite check supports the implementation, while the monotone-spine argument above establishes the general mathematical bound; neither is a new Lean proof.

## A general lower-bound principle: distinguish histories by future tests

Fix a deterministic online process with histories h, continuations z, and required answer A(h,z). Use a setting where all the continuations under discussion are admissible after every history, such as fixed-length bit prefixes followed by fixed-length bit suffixes. Define

```text
h ~ h'  iff  for every continuation z, A(h,z) = A(h',z).
```

Suppose the process retains only S(h), and every future answer is determined by S(h) and z. If S(h) = S(h'), determinism forces A(h,z) = A(h',z) for every z. Thus histories in different equivalence classes must have different summaries.

Consequently, K pairwise distinguishable histories require at least K summaries. If summaries have fixed-width b-bit encodings, then 2^b >= K and b >= ceil(log2 K). This argument is independent of additivity. For paths with typed endpoints, apply it only to histories with a common endpoint and common future tests; a continuation from one unrelated state cannot simply be appended to another.

This is the state-summary form of the standard pigeonhole argument for deterministic one-way communication and streaming lower bounds. The communication-to-streaming simulation sends the streaming memory from the prefix holder to the suffix holder. See [Roughgarden, Sections 1.7-1.8 and 3.1](https://arxiv.org/pdf/1509.06257). The proof above is supplied explicitly to state the exact assumptions used here.

## Exact example: equality needs exponential states, but only linear bits

Read x in {0,1}^n once, retain a summary S(x), then read y in {0,1}^n and answer whether x = y. Require a deterministic answer that is always correct, with no rereading of x or external storage carrying information about it.

If x != x' but S(x) = S(x'), choose the common continuation y = x. Correctness demands acceptance after x and rejection after x'. Equal summaries cannot produce different answers on the same continuation. Therefore S is injective and needs at least 2^n possible values, or n bits. This matches deterministic one-way equality's n-bit bound; [Roughgarden, Section 3.1](https://arxiv.org/pdf/1509.06257) also explains why allowing randomized error changes the communication problem.

Storing x and comparing with y achieves O(n) space and O(n) time. Hence exponential distinguishable state count is compatible with a linear-time algorithm. Exactness, one-pass access, and the accounting of all retained information are essential to the bound.

As a Boolean function, equality has a linear-size formula:

```text
EQ_n(x,y) = AND_i ((NOT x_i OR y_i) AND (x_i OR NOT y_i)).
```

In an ordered binary decision diagram reading all x bits before all y bits, the 2^n assignments to x leave 2^n distinct residual functions of y. An explicit representation of that frontier therefore requires exponentially many nodes. Interleaving x_i,y_i instead permits a linear-size diagram by rejecting at the first mismatch. This residual-function argument is a deduction for this example; variable-order dependence and canonical OBDD representations are developed in [Bryant's 1986 paper](https://doi.org/10.1184/r1/6605990) and [his 1992 account, Sections 1.2-1.4](https://www.cs.cmu.edu/~bryant/pubdir/acmcs92.pdf).

A stronger representation barrier exists even after optimizing the variable order: Bryant proves exponential OBDD lower bounds for multiplication-output functions. Multiplication remains efficiently computable by other representations and algorithms. Thus an all-order OBDD lower bound still does not establish unrestricted time hardness. See [Bryant's original 1991 paper](https://www.cs.cmu.edu/~bryant/pubdir/ieeetc91.pdf); the precise middle-output-bit consequence is also stated in Section 1.4 of the author's 1992 account linked above.

## A genuinely expensive history-summary task, with its input-size boundary

Suppose a stream inserts arbitrary elements of a universe U of size N. After the insertion phase, a query asks whether a chosen u was ever inserted. Require an exact deterministic answer, with no rereading the insertion stream.

Every subset V of U is a possible insertion history. If V != W, choose u in their symmetric difference. The membership query distinguishes the two histories. Thus at least 2^N summaries are required, meaning at least N bits. A bit vector achieves this bound up to control overhead.

If elements have n-bit names, N = 2^n and this is 2^n bits. But those histories may contain exponentially many inserted elements: this is not an exponential-space lower bound relative to the full input-stream length. Restricting the stream to polynomially many insertions permits storing its entire history in polynomial space. This proof is an application of the explicit distinguishability principle above, not a claim about SAT memory.

## Exponential work with cheap witnesses: black-box search

Let an arbitrary oracle g : {0,1}^n -> {0,1} be accessible only by evaluating one supplied n-bit argument per query. Decide whether any w satisfies g(w) = 1. A purported witness w is checked with one oracle query, besides reading its n-bit name.

Any deterministic exact algorithm requires all 2^n distinct queries in the worst case. Follow its transcript on the all-zero oracle. If it halts with a NO answer while some w remains unqueried, the oracle that is 1 only at w produces the same transcript but requires YES. Correctness rules this out. Enumerating all candidates attains the bound using O(n) query-index memory. This is the standard unstructured-search query lower bound; see [Childs, Section 19.1](https://www.cs.umd.edu/~amchilds/qa/qa.pdf).

The exponential bound is in the address/witness length n. The full truth-table input size is N = 2^n, in which the query bound is linear. The oracle model deliberately hides any succinct structure.

## Why SAT needs an additional argument

For an explicit Boolean formula F, a SAT algorithm receives F and may inspect clauses, identify contradictions, eliminate variables, learn consequences, or choose a different representation. It is not restricted to querying an unknown assignment truth table. The zero-oracle adversary cannot be changed freely after queries while keeping the same explicit F.

SAT can always be decided by enumerating assignments with polynomial space: retain F, a current assignment, and workspace for evaluation, reusing that workspace. More generally, for a polynomial-time NP verifier with polynomial-length witnesses, sequential witness enumeration uses polynomial space. These are direct algorithm constructions, compatible with the witness definition in [Cook's official P-versus-NP statement, Section 1](https://www.claymath.org/wp-content/uploads/2022/06/pvsnp.pdf).

Therefore unrestricted superpolynomial necessary working memory is not the right target for an NP separation. Exponential numbers of distinguishable configurations do not suffice either. A time lower bound must constrain how quickly an algorithm obtains a decisive answer, while allowing polynomial space, representation changes, and access to the input's structure.

## A concrete next theorem and the missing bridge

A tractable next formalization is a generic summary theorem:

1. Define a family H of histories, a common future-test type Z, and answers A : H -> Z -> Bool.
2. Assume a summary S : H -> M and decoder d : M -> Z -> Bool satisfy d(S(h),z) = A(h,z).
3. Prove that if every distinct pair of histories is separated by some z, then S is injective.
4. For finite types deduce card(H) <= card(M).
5. Instantiate equality with H = {0,1}^n, Z = {0,1}^n, and A(h,z) = (h = z).

This would provide a genuine model-specific computational-information bound beside the additive pentagon theorem. An oracle query-tree lower bound could follow as a separate theorem. Neither requires asserting that efficient algorithms must preserve the signed valuation.

For P versus NP, what remains missing is a justified simulation or reduction showing that every relevant fast algorithm fits a model in which an adequate lower bound has been proved, with polynomial overhead. A bridge that assumes exact additive descent is already refuted by the cheap state lift and efficient tree normalization. Any stronger proposal should be checked against these two examples before interpreting it as unrestricted computational hardness.
